# MartinsVet

Página institucional estática para uma clínica veterinária e pet shop. O projeto apresenta a marca MartinsVet, seus serviços e um formulário de solicitação de atendimento.

## Status do projeto

Em desenvolvimento. A estrutura HTML e a primeira versão dos estilos já estão criadas. A navegação ainda usa links provisórios, o formulário não possui processamento e o layout visual continua em evolução.

## Funcionalidades atuais

- Cabeçalho com nome da clínica e menu de navegação.
- Seção principal com chamada para a clínica veterinária e o pet shop.
- Apresentação da MartinsVet.
- Lista de serviços:
	- Consultas veterinárias.
	- Banho e tosa.
	- Produtos de pet shop.
- Formulário de contato com nome, e-mail, assunto e mensagem.
- Rodapé com identificação e ano do projeto.

## Pendências conhecidas

- Os links do menu ainda apontam para âncoras provisórias.
- O formulário não envia dados para um serviço ou backend.
- A folha de estilos ainda contém apenas estilos básicos para o corpo, as seções e o hero.

## Tecnologias

- HTML5 para a estrutura semântica da página.
- CSS3 para os estilos iniciais.
- JavaScript e backend ainda não foram adicionados.

## Como executar

Como o projeto é uma página estática, basta abrir o arquivo `index.html` no navegador. Também é possível usar uma extensão de servidor local, como o Live Server no VS Code. No estado atual, o formulário é apenas visual e não realiza o envio de mensagens.

## Estrutura

```text
.
├── index.html  # Estrutura da página
├── style.css   # Estilos atuais
└── README.md   # Documentação do projeto
```
